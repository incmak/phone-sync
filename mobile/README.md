# Twinotify mobile app

This Expo app is an Android development-build client. The custom Kotlin module
in `modules/twinotify-core` performs notification capture, pairing,
cryptography, transport, and mirror materialization. Expo Go cannot load that
module.

## Prerequisites

Use Node 20 with npm, Android Studio/SDK tooling, and an Android 14 / API 34 or
newer emulator or physical device. Android and iOS directories are generated by
Expo prebuild and are not committed.

## Supported commands

Install exactly from the lockfile, then run the TypeScript and Jest gates:

```bash
npm ci
npm run typecheck
npx expo lint
npm test -- --runInBand
```

Generate Android native output before Gradle work or a device run:

```bash
npx expo prebuild --platform android --clean --no-install
npm run android
```

For a local Android development APK, use the pinned ephemeral EAS CLI:

```bash
npm run build:dev
```

Run `make host-verify` from the repository root for host-only checks. `make
verify` performs the full protocol, relay, and native verification path.

Expo Go cannot load the custom Kotlin module. Install only with `npm ci`; this
repository is not an Expo starter-project reset workflow.
